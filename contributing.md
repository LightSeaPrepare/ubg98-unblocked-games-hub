## 🚨 Symptoms of a Broken Games Hub

Before you add another game, check whether your hub suffers from any of these classic portal symptoms. Each one points to a specific fix this guide teaches.

| **Symptom** | **What It Really Means** | **Fix This Guide Teaches** |
|-------------|---------------------------|------------------------------|
| 😵 Games won't load | Broken embed path | Relative iframe paths |
| 🐌 Slow homepage | Too many iframes | Lazy-load cards |
| 🧊 Search returns nothing | No index | Client-side search index |
| 🔥 Blocked by network | Suspicious domains | Clean hosting + HTTPS |
| 📉 Mobile unusable | Fixed layout | Responsive grid |
| 🔇 No categories | Flat list | Tag-based filtering |

> **💡 Tip:** If games won't load, it's almost always a broken iframe path — use relative paths, not absolute local files.

## 🚀 First 5 Minutes — Minimal Working Example

The fastest way to launch a working games hub.

**Step 1 — Index page.** Create `index.html` with a game grid.

**Step 2 — One game.** Add a single embedded HTML5 game.

**Step 3 — Card link.** Point the card to the game page.

**Step 4 — Test.** Open locally and confirm the game loads.

**Step 5 — Deploy.** Push to a static host.

> **💡 Tip:** Always test a game in an iframe before adding it to the catalog — some games break under iframe restrictions.
